SOURCE: lessons derived by another agent from the user's litigation records (anonymized). Treat as the factual basis; do not add facts beyond it.

1. Look up the agent before you pick an address. Corporation served through agent on SOS record or person statute treats as one (CCP 416.10). Truck-dealer file: bizfile pull named two different individual agents at two addresses. Earlier attempt used seller's old lot for newer company - not service on agent.
2. Trade name on door is not the entity. Two stock corporations formed years apart, similar names, each own agent. Serving manager at shared lot did not serve the corporation whose agent lived in another county. Capacity matters as much as address. CCP 412.30: summons that does not warn the corporation (notice of capacity) can block a default.
3. Sheriff is cleanest serve when fee waiver granted. Two carrier cases: fee waiver granted, Judicial Council SER-001 to sheriff in county where registered agent sat; sheriff served within four days. One agent CSC, other CT Corporation System. Each return named authorized employee and cited 416.10. No dollar fee because waiver applied. Later a private server asked a flat fee to serve two entities at same CT Corp address; fee not in file.
4. Fill the sheriff form the way the sheriff reads it. Sheriff rejected a SER-001 the day it arrived: item 3b(2) must be blank when 3b(3) names an agent for service. Corrected form drafted; resubmission not shown.
5. Right lot, wrong person is still a bad return. Server served a manager; proof checked service on an individual. Don't start corp's response clock or request default on that proof. Next serve must name agent; proof must match.
6. Substitute service on a person is two steps. Registered server made two attempts, left papers with HR person. Invoice $134. Follow-up mailing under 415.20(b) went later with certificate of mailing. Complete on 10th day after mailing. Default request filed on leaving date was declined.
7. Proof must list papers and person. Clerk declined both defaults: one motion didn't say papers left with person of suitable age; other proof didn't list documents served. Postage receipt or docket "served" line isn't that list.
8. Don't hold service for a caption fix. E-filing system entered Doe defendants first producing wrong short title; issued summons still named companies. Serve by ~60th day and file proof regardless. CRC 3.110(b): service and proofs filed within 60 days after complaint filed.
9. After removal, don't restart a clock that already ran. Carrier served by sheriff before removal; federal scheduling order put service of that order on defendant; FRCP 4(m) 90 days didn't run against plaintiff. Federal individual-capacity case: Rule 4(e) adopts state substitute-service method; state mailing rule still controlled completion.
10. Acceptance and waiver are service only when paper says so. One defendant accepted service through counsel on stated date. Another stipulated service challenges waived and a default was vacated. A notice served had no clerk stamp on proof - don't treat unstamped proof as live clock. NAM (notice and acknowledgment) offered in meet-and-confer draft.

CHECKLIST (from source): confirm exact entity name on bizfile; print agent statement (agent, address, county); choose server (sheriff/marshal if fee waiver; else registered server or adult non-party; plaintiff doesn't serve); pick method (personal first; substitute after diligence + mailing; NAM or Rule 4(d) waiver only if other side signs); list every document (summons, complaint, case-management/ADR papers); on SER-001 leave individual box blank if agent box filled; calendar 60 days (CRC 3.110) / 90 days (FRCP 4(m)); check return for person, capacity, documents, date (+10 days for substitute); file the proof; start response clock from completion.
